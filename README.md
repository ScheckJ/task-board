# task-board

## Description

The goal of this challenge was to modify starter code in JavaScript to produce an application that allows for users to create tasks that can be moved into different categories. This required the use of of JavaScript and Bootstrap

## Usage

This webpage can be used create tasks and drop them into categories of to-do, in-progress, and done. Users are provided the functionality to move tasks into different categories at their discretion. Tasks are created with dates attached, and and the task's color will correspond with how soon the task must be completed.

[Webpage] https://scheckj.github.io/task-board/
